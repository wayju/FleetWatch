# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which is incorporated here by reference. Its pledge, standards, enforcement responsibilities and enforcement guidelines apply to all project spaces, including issues, pull requests and discussions, and to anyone representing the project in public.

In short: be respectful, accept constructive criticism, focus on what is best for the project, and do not harass or demean anyone. Contributions written with AI assistance are held to the same standard as any other.

## Reporting

To report unacceptable behaviour, open a private report through GitHub security advisories for `wayju/FleetWatch` (the repository's **Security** tab, then **Report a vulnerability**), and say that it is a conduct report rather than a security issue. For behaviour that is not sensitive, you can open an issue. Reports are reviewed and investigated promptly and fairly, and the privacy of the reporter is respected.

Maintainers who do not follow or enforce the Code of Conduct may face consequences as determined by the other project leaders.
